# assinaturas

Images and copy page for the Oz email signature.

- `faixa.png`: glass banner, same for everyone.
- `fotos/<name>.png`: one round photo per person (made with the photo generator).
- `index.html`: fill in name, role and phone, click copy, paste in Gmail.

Served with GitHub Pages at https://apollo-space-ai.github.io/assinaturas/. Everything here is public.
